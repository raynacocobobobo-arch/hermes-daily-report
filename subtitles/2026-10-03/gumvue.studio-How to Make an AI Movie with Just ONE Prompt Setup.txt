Hello everyone. Today, I'm going to show
you how to create your first movie using
AI with Gum View Studio, ChatGPT, Dream

First, I'm going to log in to my Gum
View Studio account. If you don't
already have an account, click create
account, complete the registration
process, and sign in.
Once you're logged in, you'll see
several different tools. The one we're
going to use is the MCP server
connector. First, create your API key
and choose how long you want it to
remain active.
Once it has been generated, copy the MCP
server link. Next, go to your Claude
account.
I have already connected Gum View
Studio, but I'll show you how to add a
new connection. Go to manage connections

Paste the MCP server link you copied
from Gum View Studio. Enter Gum View
Studio as the name.
Click continue, and then select add.
Once the connector has been added, click
authorize.
After authorization is complete, return
to the connectors section. You should
now see that the Gum View Studio
connector is ready to use.
The next step is to find the master
prompt. Copy the entire master prompt
and select the script you want to use
for your movie. Paste the master prompt
along with your script into Claude and
instruct it to use the Gum View Studio
MCP server. Claude will begin processing
the script and generating the required
content. Once the process is complete,
open the result and copy the generated
prompts.
The system creates scene by scene
prompts that you can use for video
generation.
You'll find detailed information for
each scene, including character
descriptions, props, locations, and
other visual elements.
For example, you can copy a character
description and paste it into Chat GPT.
Ask Chat GPT to generate an image based
on that character description. This
gives you a visual reference for the
character that you can use throughout
the filmmaking process.
The screenplay section contains the
story,
while the prompt section contains the
individual prompts for generating each
shot. For example, one sequence may
contain three shots with a total
duration of approximately 28 seconds.
Next, I'll go to Dreamina and start a
new video generation project.
Here, I can upload the character images
that I generated earlier.
This allows me to maintain visual
consistency when generating the video. I
can also generate additional characters
if the story requires them.
The same process can be used for
locations.
Copy the location descriptions and use
them to generate reference images.
As you can see, the quality of the
generated images is very good. Once the
location images are ready, download them
and add them to your Dreamina project.
Another useful approach is to create a
storyboard.
Copy the relevant scene information and
ask Chat GPT to create a storyboard
image with individual panels for each
shot. You can instruct Chat GPT to use
the characters and locations that were
already created. This gives you a visual
representation of the sequence before
you begin generating the final video.
Claude has generated this section very

Now, we can return to Dreamina. We
already have our character references,

creation generator.

story and select the storyboard option.
The system will analyze the story,

In this example, there's a significant

A better approach would be to divide the

This is one of the advantages of using
Chat GPT to structure your scenes. It
can divide longer dialogue sequences

to fit everything into a single scene.
For example, instead of placing an
entire minute of dialogue into one shot,

This improves the pacing, gives the
